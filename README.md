# ODONTO

ODONTO Does Observation, Not Training Only.

ODONTO é um visualizador web em modo somente-leitura
para bases de dados de radiografias panorâmicas no formato COCO.
Seu objetivo é permitir inspeção, depuração e análise visual
de anotações (bounding boxes e segmentações), sem qualquer
modificação na base de dados original.# odonto
